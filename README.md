# ❤️ HANOTE - Aplikasi Tugas Berpenuh Cinta

Aplikasi manajemen tugas untuk kamu dan pacar. 
Dibuat dengan cinta 💕

## Fitur
- 📝 Manajemen Tugas
- 📅 Jadwal Kuliah
- 📓 Catatan Harian
- 📸 Galeri Foto Berdua
- 💌 Quote Cinta
- 📊 Statistik Tugas
- 🔔 Notifikasi Deadline
- 🌙 Dark Mode

## Teknologi
- Backend: Node.js + Express + MongoDB
- Frontend: HTML + CSS + JavaScript

## Cara Install
1. Clone repository ini
2. `cd backend && npm install`
3. Buat file `.env` dengan MONGODB_URI
4. `node server.js`
5. Buka `index.html` di browser
